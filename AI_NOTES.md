### Формат экспорта
`/export` (txt) сворачивает результаты инструментов (`Read 1 file (ctrl+o to expand)`), что видно в пробной сессии.
Поэтому основной формат — исходные JSONL-транскрипты Claude Code (`~/.claude/projects/<проект>/*.jsonl`,
включая транскрипты субагентов), скопированные скриптом `npm run sessions:export` без сокращений.
